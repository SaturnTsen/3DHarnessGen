## 核对与复现

- 429 条动态发现返回的分段重新编码后，均与上一层实际 token 归属精确一致，边界差值全部为 0。
- 尾随文档移出后，全部 6,941 条样本的总长度与分项合计逐条核对，保持一致。主表与原组成报告当前分类总量一致。
- 普通工具文本分项加总严格等于 65,315,374 token，即完整训练候选的 20.94%。
- 当前结果保存于同名 JSON；细分消息和工具条目的索引位于 `temp/tool_return_breakdown/`，不包含新导出的训练对话。
- 初次完整组成统计由 `temp/token_composition/analyze.py` 生成，随后运行 `temp/tool_return_breakdown/analyze.py`、`revise_composition.py` 及 `temp/token_composition/finalize.py` 完成内容细分、尾随文档修正和报告整理。修正脚本仅对首轮统计执行一次。

统计表的平均值统一以 5,583 条训练候选为分母，表示一条训练输入平均携带的数量，不是单次工具返回的平均长度；占比统一为完整输入占比。每条完整输入平均 55,863.2 token。

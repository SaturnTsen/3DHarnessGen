## 方法与限制

- 顶层调用读取归档 assistant 的 tool_calls，不执行任何代码。exec 内部调用通过助手调用源码中的显式 tools.name(...)、tools["name"](...) 位置识别。
- 上述未使用的内嵌接口不仅没有显式调用，其名称也没有出现在任何 assistant 调用源码中。轨迹存在动态 tools[变量] 调用，主要指向 Blender 接口；静态统计不是完整运行时追踪。
- 通过诊断标记定位 Qwen 实际渲染的每个工具 JSON，移除标记后与原模板逐字一致；对描述字符串的 JSON 转义同步定位，逐 token 归属合计严格等于 9,591。
- 此结论只说明现有轨迹中的使用情况，不代表其他任务永远不需要这些工具。后续精简应采用固定任务规则，不能按当前目标答案决定保留哪些工具。
- 未修改原始轨迹、模型、图片或训练实现。脚本和原始统计保存在 `temp/initial_tool_audit/`，完整结果见同名 JSON。

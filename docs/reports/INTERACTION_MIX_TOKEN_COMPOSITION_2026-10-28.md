# Interaction-mix：Qwen 27B 输入 token 组成（2026-10-28）

统计入口为 `configs/sft_interaction_mix_27b_fsdp.yaml`，使用其本地 Qwen3.8-27B Processor、分词器和图片预算。仅读取数据与 Processor，未加载模型权重、未启动训练，也未删减或改写原始轨迹、图片及训练实现。

数据共 100 个对象、200 条会话、6,941 个训练目标；训练候选 5,583 条，验证 588 条，测试 770 条。数据及图片检查拒绝 0 条。

## 口径

- 主表只统计训练候选，包含超过长度预算的样本。历史随每个训练目标重复出现，就重复计数；不把每条原始消息只计算一次。
- 百分比为该类别 token 总量除以该组样本完整输入 token 总量；“平均 token”是每条候选样本平均携带的量。
- 全部输入包含提示词、工具说明、历史、图片及当前目标；无补齐、无截断。当前配置的长度预算为 49,152。
- 工具发现依照调用代码中的 `ALL_TOOLS` 与返回的 MCP 名称/说明识别。混合技能文档与工具列表的返回，在可识别的列表边界拆分；无法可靠拆开的发现/执行混合返回单列。
- 未判断语义相关性。“其他工具返回”不能直接称为“无关工具返回”，也不代表可以全部删除。
- 消息的角色、工具调用格式标记归入相应消息；全局模板框架单列。当前 assistant 目标包含整条 assistant 消息，不等同于参与损失计算的标签数量。图片栏只计展开后的 image-pad token。

## 验证与可追溯记录

- 所有诊断标记移除后，与原 Qwen 模板输出逐字相同；每条样本的分项之和严格等于完整输入 token 数。
- 检查了所有样本的历史索引，均为完整前缀；对 200 条会话各自的首个、中间及最后目标独立重新分词，共 600 次，token IDs 与前缀计算完全一致。
- 独立运行完整 Processor 核对 21 条样本，覆盖最长 10 条，以及各场景和数据集合的极端长度，全部一致。超限样本由正式模板报告实际编码长度。
- 全部 6,941 条长度与已有逐样本长度记录一致；独立 27B 长度报告的总 token 数亦一致。
- 200 条会话中仅有 5 个 token 跨越类别边界，按 token 起始字符归类；不影响总长度。分类描述有规则边界，不能据此判断可删除的信息量。
- 完整机器可读统计为同名 JSON。逐样本组成及原始消息重复次数分别保存在 `temp/token_composition/sample_composition.csv`、`message_composition.csv`；均为统计索引，不是重新导出的训练数据。
- 统计脚本与运行日志在 `temp/token_composition/`。JSON 保存入口、模板及源文件集合指纹。

## 分类修正

进一步拆分发现，部分工具列表后还打印了技能文档。初次粗分将这些尾随文档计入动态工具说明，现已重新归入工具返回的技能文档：训练候选中转移 6,031,134 token，涉及全部会话中的 71 条返回。动态工具说明占比从 19.87% 修正为 17.94%，技能文档占比从 3.31% 修正为 5.24%。样本总长度、对象划分、其他类别和原始数据均不变。详细拆分及逐 token 核对见 `INTERACTION_TOOL_RETURNS_2026-10-28.json`。
